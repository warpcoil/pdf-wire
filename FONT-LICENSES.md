# Font licences

`index.html` contains subsetted copies of the fonts below, which are embedded in exported PDFs. Every font is licensed under the **SIL Open Font License 1.1** (see [OFL.txt](OFL.txt)), and none declares a Reserved Font Name.

The subsets keep each font's original name table, including its copyright and licence notices. The fonts were taken from the [Google Fonts repository](https://github.com/google/fonts). Variable fonts were turned into static regular, bold, italic and bold italic instances, then subset to Latin-1, Latin Extended-A and common punctuation.
